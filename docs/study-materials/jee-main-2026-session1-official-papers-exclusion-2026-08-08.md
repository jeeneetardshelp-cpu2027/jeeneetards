# JEE Main 2026 Session 1 official-paper exclusion

No JEE Main 2026 Session 1 B.E./B.Tech. Paper 1 PDF is included in the
production seed.

The [official JEE Main documents page](https://jeemain.nta.nic.in/documents/)
and [official sitemap](https://jeemain.nta.nic.in/sitemap/) were checked on
8 August 2026. The official question-paper section exposed nine April 2026
Session 2 Paper 1 PDFs, which are already handled by the Session 2 package,
but it did not expose any January 2026 Session 1 Paper 1 PDF. The documents
page retained Session 1 notices and answer-key material, not complete
shift-wise question-paper PDFs suitable for this catalogue.

No coaching-site reconstruction, memory-based paper or candidate response
sheet was substituted. A future production package should be prepared only
after complete official copies become available or the user supplies
redistribution-approved originals.
