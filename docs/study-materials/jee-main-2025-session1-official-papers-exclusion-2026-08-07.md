# JEE Main 2025 Session 1 official-paper exclusion

No JEE Main 2025 Session 1 Paper 1 PDF is included in the production seed.

The official NTA download API exposed eight distinct live B.Tech PDFs for 22,
23, 24 and 28 January 2025. All 533 pages were rendered and visually checked.
Every PDF omitted exam content: failures ranged from a blank first page that
left only Question 1's options, to isolated missing questions, to multi-page
blocks that skipped several consecutive questions. The two 29 January Paper 1
shifts were not present in the official download catalogue.

The NTA API also mislabels the two 24 January records as older papers, although
their PDF headers identify the correct 2025 dates and shifts. This catalogue
error does not change the exclusion decision.

No third-party reconstruction or coaching-site copy was substituted. A future
production package should be prepared only after complete official copies are
available or the user supplies redistribution-approved originals.
